# ASK SARTHI – Your AI Career GPS

A single-page career guidance web app built with HTML, CSS and JavaScript.

## Run locally

Open `index.html` in a modern browser.

## Repository structure

- `index.html` — complete app (HTML, CSS and JavaScript)
- `README.md` — project documentation

## Notes

The app references Google Fonts and several external career/education resources, so an internet connection may be needed for some features and external links.
